# Privacy

TOCguide does not collect personal data, set marketing cookies, or call remote APIs.

Optional ItemList JSON-LD is printed in page HTML only if a site owner enables it under **Settings → TOCguide**. That markup is public document data, not a tracker.

WordPress itself stores plugin settings in the `tocguide_settings` option and, if used, a per-user flag that dismisses the welcome notice. Uninstall deletes those only when the owner opted in.

Security reports: see [SECURITY.md](SECURITY.md) or email **matt@matthummel.com**.
