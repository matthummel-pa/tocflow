Support policy

We answer the plugin, not the whole site.

TOCflow support is in English. The canonical channel is GitHub. Envato buyers also use the item support tab during their support window.

Bugs & features

Docs
documentation.html · in wp-admin: Settings → TOCflow → Docs & Support

Security
Do not file a public issue. Email matthew.r.hummel@gmail.com — see SECURITY.md.

Include in a bug report

  • WordPress, PHP, and TOCflow versions
  • Theme name
  • Block, shortcode, or auto-insert
  • Steps and a screenshot if the outline is wrong

Covered

TOC generation, anchors, auto-insert, shortcode, settings, compatibility with the advertised WordPress version.

Not covered

Custom theme CSS beyond documented classes, general WordPress admin, hosting, or same-day SLAs. We will still try to name a conflicting plugin when the_content is rewritten.

Privacy

TOCflow does not collect personal data, set marketing cookies, or call remote APIs. Optional JSON-LD is printed in page HTML only if you enable it.
