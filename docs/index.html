Chapter 01

What to call it

On GitHub, WordPress.org, and in wp-content/plugins/, the name is the slug:

tocflow

Display name TOCflow. Directory title can read “TOCflow – Table of Contents Block.” Do not rename the repo to wp-toc or toc-flow-plugin — invented brands stay one lowercase token, same idea as Akismet or Jetpack. Full naming notes.

Chapter 02

What it does

Live preview

The editor outline updates as you add Heading blocks. No placeholder-only box.

Server-rendered

The <nav> is in the first response. Search engines and screen readers see it immediately.

Honest anchors

IDs are injected with the same slug map the list uses. Custom HTML anchors win.

Auto-insert

Optional site-wide TOC at the top of content or after the first heading.

Shortcode

[tocflow] for classic content and theme templates.

Reading aids

Smooth scroll + offset, collapse, sticky, scroll-spy. Reduced motion is respected.

Chapter 04

Quick start

  1. Install and activate the plugin from the latest ZIP.
  2. Edit a post that has Heading blocks.
  3. Insert Table of Contents.
  4. Optional: Settings → TOCflow for scroll offset and auto-insert.

Skip a heading by adding the CSS class no-toc on that Heading block.

Chapter 06

FAQ

Is the GitHub repo supposed to be called something else?

No. Keep it tocflow. That is the WordPress plugin slug and the text domain.

Classic Editor?

Use [tocflow].

Does it phone home?

No remote APIs, no tracking, no accounts.

Where do I file a bug?

GitHub issues. Security: see the support page.
