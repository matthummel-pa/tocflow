TOCflow

A server-rendered Table of Contents for the WordPress block editor. GitHub and WordPress.org slug: tocflow.

1. Install

  1. Download tocflow.zip from GitHub Releases (or your marketplace purchase).
  2. WordPress → Plugins → Add New → Upload Plugin.
  3. Activate. Open Settings → TOCflow.

Developers: clone the repo into wp-content/plugins/tocflow, then npm install && npm run build.

2. The block

Insert Table of Contents in a post that contains Heading blocks. The editor shows a live outline.

SidebarPurpose
Title show/hide and title elementVisible label; paragraph or H2–H4
H1–H6 togglesWhich levels appear (H1 off by default)
Numbered list / nested numberingBullets, 1 2 3, or 1.1.1 counters
Hide markers, two columns, compact, underline, max heightLayout
Style presetStyles panel: default, minimal, boxed, underline, card
Sticky / collapsible / highlight / smooth scrollReading behavior; smooth scroll can inherit the site setting
Minimum headings / scroll offset override-1 = use site setting

Skip a heading: additional CSS class no-toc or tocflow-skip.

3. Site settings

Settings → TOCflow

  • Smooth scroll (honors reduced motion)
  • Scroll offset in pixels (sticky header clearance)
  • Highlight the heading in view
  • Minimum headings before a TOC prints
  • Auto-insert: off, top of content, after first heading + post types
  • Optional ItemList JSON-LD
  • Delete settings when the plugin is deleted (never on deactivate)

4. Shortcode

[tocflow]
[tocflow title="On this page" ordered="1" numbering="nested" style="boxed" collapsible="1"]

Attributes: title, showtitle, titletag, h1–h6 (1/0), ordered, numbering (default or nested), markers, collapsible, collapsed, sticky, compact, columns, underline, highlight, maxheight, min, smooth (inherit/on/off), style.

5. Theme CSS

Hooks: .tocflow, .tocflow--boxed (and other presets), .tocflow.is-sticky, .tocflow.is-collapsed, .tocflow__link.is-active, .tocflow__title.

6. Developers

  • Block: tocflow/table-of-contents
  • Heading map: TOCflow_Headings::get_all( $post_id )
  • Do not declare functions in src/render.php
  • Text domain literal: 'tocflow'
  • Build: npm run build

See DEVELOPER_SOP.md and NAMING.md.
