# Marketplace kit

TOCguide is one **100% GPLv2 or later** plugin. You can list it in more than one place; the **slug never changes** (`tocguide`). See [NAMING.md](../NAMING.md) and [licensing.md](licensing.md).

| Marketplace | What TOCguide is there | Doc |
| --- | --- | --- |
| [WordPress.org Plugin Directory](https://wordpress.org/plugins/) | Free listing, `readme.txt` driven | [wordpress-org.md](wordpress-org.md) · [FAQ/guidelines](../wordpress-org/PLUGIN_DIRECTORY.md) |
| [CodeCanyon](https://codecanyon.net/) (Envato) | Paid WordPress **plugin**, 100% GPL | [codecanyon.md](codecanyon.md) |
| [ThemeForest](https://themeforest.net/) | **Not** a plugin store. Bundle or recommend `tocguide` from a theme | [themeforest.md](themeforest.md) |
| License | 100% GPLv2 or later (not Envato split) | [licensing.md](licensing.md) |

WordPress **plugins cannot be submitted to ThemeForest**. ThemeForest is themes; CodeCanyon is the Envato plugin catalog. Theme authors *feature* a TOC by requiring this plugin, which is the ThemeForest-compliant pattern (functionality lives in a plugin, not the theme).
