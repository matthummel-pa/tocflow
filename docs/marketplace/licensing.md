## What “100% GPL” means here

Everything in the distribution is GPL-compatible: PHP, JavaScript, CSS, images, and docs that ship in the plugin. WordPress.org [guideline 1](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/) requires that. Prefer the same license as WordPress: **GPLv2 or later**.

Do **not** use Envato’s default **split license** (PHP under GPL, CSS/JS/images under the Regular License). Split licensing fails WordPress.org review. Envato allows a **100% GPL** listing for WordPress plugins; use that option. It cannot be reversed on that item once chosen.

## Selling is allowed

The GPL lets you charge for copies, support, and convenience. A CodeCanyon purchase is payment for the packaged zip, documentation, and item support — not a proprietary lock on the PHP.

Do **not** add license keys, trialware, or remote checks that only unlock code already in the zip. That violates WordPress.org guideline 5 and is not needed to sell the plugin.
